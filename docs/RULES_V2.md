## Caveats

- The synthetic loans are generated with the textbook amortization formula and whole-year terms, so the amortization, term and balance rules fit this data exactly. Real loans carry escrow in the payment, ARMs, modifications, odd first periods and curtailments: expect more false alarms, and tune the tolerances on a sample of real loans before turning a rule on.
- Planted misreads test the rules alone, without the confidence score; in routing, a value goes to review if any check fires.
- Real misreads are few (see the table): the planted test is what gives the catch rates.
